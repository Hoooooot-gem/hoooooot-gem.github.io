## LUT 导入：色彩空间识别 + 非 Rec.709 确认弹窗

- 新增 `tools/2026/LUT/lut-colorspace.js`（约 240 行），`app.js` 仍未改。
- 只读元数据，不做像素反推：`.cube` 扫 TITLE / `#` 注释 / `DOMAIN_*`（前 256KB），`.png` 扫 tEXt / iTXt（前 512KB）；元数据为空时退回文件名（`SLog3_to_Rec709`、`BT2020` 等）；`DOMAIN_MIN/MAX` 超出 0–1 判为「扩展输入域」。
- 判定：Rec.709 / Rec.2020 / 其他已知（P3、ACES、Log、Adobe RGB、ProPhoto）/ 未标注 / 同时提到多个（ambiguous）。`A to B`、`A -> B`、`A→B` 取箭头左侧为输入空间；`input|source|from` 行优先级最高。
- 未知策略：`STRICT_UNKNOWN = false`，未标注按 Rec.709 放行（绝大多数 .cube 无标注，否则每次导入都弹）。改 true 即严格模式。
- 拦截：capture 阶段监听 host 的 change，`stopImmediatePropagation` 早于 app.js 的冒泡监听；识别完再用 `bypass` 标记合成 change 交还原流程。选「否」只清空 `input.value`，不触发任何解析。
- 弹窗：`role=alertdialog`，文案按需求原文，列表只列被拦下的文件 + 识别结果（红色）；「是」为墨色主按钮并默认聚焦，「否」为描边；Esc / 点遮罩 = 否；焦点锁在两个按钮间，关闭后回到「选择本地 LUT」。
- 验收：Rec.2020 元数据弹窗、否不导入且 input 清空、是导入；Rec.709 与未标注不弹；标题/文件名 `Rec2020 to Rec709` 与 `SLog3_to_Rec709` 能识别为 2020 / Log；DOMAIN 超范围弹「扩展输入域」；混合多选只列非 709、选是后全部导入；无 console 异常。
