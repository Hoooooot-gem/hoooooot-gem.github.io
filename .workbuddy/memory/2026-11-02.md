新增文件：

- `egg/index.html` — 彩蛋页（占位实现，`/egg/`，已加 `noindex`）

改动文件：

- `index.html` — 中国版 / 国际版两处 `.contact-mail` 的 `<a mailto:>` 全部替换为
  `.mail-field > input.mail-input + span.mail-bubble`；页尾引入 `js/easter-egg.js`
- `css/home.css` — 新增 8b 段（输入框去控件外观、气泡与尖角），
  响应式段补窄屏气泡，减弱动态段补气泡降级；
  `.contact-block .social-links` 的 `margin-top` 由 44px 改为 `clamp(56px, 5vw, 72px)`，
  给气泡留出显示空间，避免压住社交图标

关键实现点（后续改动别踩）：

- 输入框宽度由 JS 用隐藏测量节点实时算，`field-sizing: content` 只作脚本执行前的兜底；
  宽度必须跟随内容，否则会露出输入框的默认宽度
- 气泡 `pointer-events: none`，定位每次按输入框实际位置重算并夹在视口内，
  尖角用 CSS 变量 `--tail-x` 指向输入框中心（气泡被推到边缘时尖角仍对准）
- `Enter` 判定要跳过 `isComposing`，否则中文输入法组词回车会误触发
- 触发词 `OMG`（忽略大小写与首尾空格）→ 跳 `/egg/`，其他任何内容 → 气泡「干啥」停留 4 秒

验证方式：本地 `python3 -m http.server` + Edge headless 截图核对
（注意：headless 下 countries.dev 地区检测会左右首页显示哪一版，
`#contact` 锚点跳转在无头截图里不可靠，核对时改为抽出联系区片段做独立页面）。

## 彩蛋页定稿：二段式「你是怎么找到这里的」

约束：不新增任何图片 / 视频，只用文字 + CSS/JS。

做法（`egg/index.html` 单文件，样式与脚本都内联）：

- 第一拍：问「你是怎么找到这里的？」，三个胶囊按钮
- 第二拍：按选择给一句不同的回应（`data-ack`），随后露出 2024 那一年
  （首页 `.tl-list` 只有 2025 / 2026，正好缺 2024，条目因此成立）
- 两拍叠在同一个 grid 单元（`grid-area: 1/1`），行高取较高者，
  切换时页脚不跳；未展开的一拍用 `visibility: hidden` 摘出点击与 Tab 序
- 展开后把焦点移到 `.egg-answer`（`tabindex="-1"`），读屏用户不停在消失的按钮上
- 逐条入场延迟 0.12 → 0.58s，`prefers-reduced-motion` 下退化为纯淡入

改文案的位置：按钮上的 `data-ack`、`.egg-entry` 里的年份与正文，不用动 JS。
