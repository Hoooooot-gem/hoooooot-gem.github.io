# 2026-11-01

## 站点新增「商店」入口与 /store 页面

改动范围（均在 hoooooot-gem.github.io 内）：

- `header.html`：在「开发」前插入 `<li><a href="/store">商店</a></li>`，其余导航项未动。
- `index.html`：在「关于」与「画廊」之间插入 `#store` 区块（中国版 / 国际版各一份），
  三栏细线清单 + `.store-btn` 胶囊按钮 → `/store`；注释编号顺延（画廊 4 / 历程 5 / 实用 6 / 联系 7）。
- `css/home.css`：新增第 5 节「商店」样式（三栏网格、胶囊按钮、窄屏单列全宽按钮），
  后续章节编号顺延至 10；reduced-motion 补 `.store-btn`。
- `css/store.css`（新）：`body.store` 作用域。覆盖 pages.css 的 `main` 顶部留白为 0，
  静态 Hero（`min(88svh,820px)`，设计稿原样呈现、**不叠遮罩**；白字落在设计稿中央实色蓝
  #01A1FF 块面上，对比约 2.8:1，仅用一道紧投影提字口），黑色发售提示条、
  `.product` 卡片网格、`.notes-list` 须知、收尾 CTA。
- Hero 为浅色设计稿，顶栏沿用 pages.css 的深色文字；原先的白色反白与 `:has()` 补丁已删除。
- **对齐规范（商店页）**：除 Hero / 顶栏 / 底栏外全部左对齐，唯一左边界是 `.store-wrap`
  的 clamp 内边距。`.page-head`、`.page-lead` 覆盖 pages.css 的居中与 auto 外边距；
  `.store-notice` 改为 `padding:15px 0` + 内嵌 `.store-wrap`；`.notes-list` 去掉 `margin:auto`；
  `.store-cta` 左对齐；`.product-foot` 由 space-between 改 flex-start（价格与按钮同排靠左）。
- **Hero 标题与首页同规格**：`.store-hero-title`（store.css）改为 font-size 1.8rem /
  font-weight `var(--font-weight-bold)` / letter-spacing 0.02em，对齐 style.css 的 `.hero-title`；
  原 clamp(2.5rem,6.6vw,5rem) 与 0.14em 字距（含抵消用负 margin）已删除。两边均无断点覆盖。
- **地域提示弹窗**：`store/index.html` 末尾 `.region-gate`（role=dialog，默认 hidden）+ 独立内联脚本，
  沿用首页 `fetch('https://countries.dev/ip')` → `countryCode !== 'CN'` 的判据；接口异常不拦人。
  「是」关闭，「否」→ 站内来路 `history.back()`，否则 `location.replace('/')`。
  Tab 在两个按钮间循环；`html.gate-open` 锁滚动；样式在 store.css 第 8 节。
  自查开关：`/store/?region=non-cn` 强制弹出（国内网络默认看不到）。
- `store/index.html`（新）：Hero「触手可及」+「仅在中国大陆地区发售」黑色提示条 +
  4 件商品（套装 ¥67.73 / LUT Premium ¥46.99 / 2027 明信片 ¥24.30 / 每月 ¥20.00）+
  下单须知 + 页尾 CTA，全部购买按钮指向 https://afdian.com/a/hoooooot。
- `images/store-hero.webp`：由 `temp/store-hero.webp` 复制（3840×1280，白底蓝色块面）。

设计要点 / 坑：

- 全局 `a:hover{opacity:.6}` 会让按钮发灰，home 与 store 各自覆盖为 `opacity:1`。
- 顶栏由 `js/components.js` 异步 fetch 注入，子页面拿不到 `.navbar`，
  商店页用 MutationObserver 等它出现再绑滚动毛玻璃；导航高亮纯用 CSS 属性选择器，不依赖脚本。
- `pages.css` 在 ≤767px 用 `!important` 把导航文字压黑（移动端菜单是白底），商店页不需再覆盖。
- 商店页 Hero 顶格，必须覆盖 `body.page.has-chrome > main` 的 padding-top。
- 爱发电页面是 SPA，curl 拿不到商品；用本机 Edge `--headless=new --dump-dom` 渲染后才取到真实商品名与价格。
  该命令后续被权限规则拦下（会删 Edge 临时 profile），不要再尝试用无头浏览器截图。
